# NuroBin
This is the Repo for our EPIC project.

## Goals
The project is made to help patient's suffering from early stages of **Dementia** and help them work in society and get the help they deserve.
This is a open source project so anyone may use it or host for their own use.

## Current Dependencies
* **Python** version 3.10 or above
* **Docker(optional)** for quick hosting

## Installation/Setup
> *Note:* it is suggested that you use docker as it is easier
1. **Install Python Dependencies**
```
pip install -r requirements.txt
```

2. **Setup the environment variables by coping the .env.example in the project root and make your .env file**
```
cp .env.example .env
```

3. **Update the .env file based on the comments**

## Testing
1. Simply run the following code:
      ```
      pytest -v tests
      ```
